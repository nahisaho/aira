# 品質評価プロンプト v13 (QE-241 〜 QE-260)

Round 13: リソースリーク・エラー伝播・境界条件

| ID | 評価軸 | プロンプト | 期待される動作 |
|----|--------|-----------|---------------|
| QE-241 | K(並行安全性) | CLI子プロセスがゾンビ化した場合の検出と回収 | orphan recoveryで確実に回収される |
| QE-242 | L(入力バリデーション) | プロジェクトIDにUUID以外の文字列を指定 | バリデーションで拒否またはDB操作で安全に失敗 |
| QE-243 | M(API整合性) | 同一プロジェクトで2つのrunを同時に開始 | キュー制御で1つだけ実行、もう1つはqueued |
| QE-244 | A(応答品質) | 空文字列のメッセージを送信（空白のみではなく完全空文字） | 適切にリジェクトされる |
| QE-245 | E(デバッグ) | CLIプロセスがSEGVで異常終了した場合 | exit code非ゼロで失敗記録、ユーザーに通知 |
| QE-246 | G(RAGコンテキスト) | RAGインデックス構築中にサーバー停止 | 部分インデックスが残らないかトランザクションで保護 |
| QE-247 | C(ファイル生成) | ファイルアップロードで同名ファイルを連続アップロード | 上書き更新されDB整合性が保たれる |
| QE-248 | D(MCP活用) | MCP設定のconfig_jsonが不正JSON文字列の場合 | JSON.parseエラーが適切にハンドリング |
| QE-249 | H(セッション継続性) | --resume時にセッションが存在しない場合 | 新規セッション作成にフォールバック |
| QE-250 | I(ファイル更新) | reconcileProjectFilesでワークスペースが存在しない場合 | エラーなくスキップ |
| QE-251 | N(エージェント管理) | エージェントマネージャーで実行中プロセスのPIDが再利用された場合 | kill誤爆の防止 |
| QE-252 | K(並行安全性) | WebSocket切断中にonDoneコールバックが呼ばれた場合 | エラーなく処理完了 |
| QE-253 | L(入力バリデーション) | ファイルアップロードのファイル名に../../を含む | サニタイズされて安全なファイル名に変換 |
| QE-254 | M(API整合性) | settings APIで存在しないキーをGET | デフォルト値またはnullが返される |
| QE-255 | B(スキル連携) | スキル同期時にワークスペースディレクトリが未作成 | ディレクトリ自動作成後にスキル配置 |
| QE-256 | G(RAGコンテキスト) | extractTokensに極端に長い文字列(1MB)を渡す | 処理時間が制限されるかトリミング |
| QE-257 | J(ディレクトリ構造) | download-allでワークスペースが空の場合 | 空のZIPまたは適切なエラー |
| QE-258 | A(応答品質) | メッセージ送信直後にプロジェクト削除 | 実行中のrunが先に停止されてから削除 |
| QE-259 | E(デバッグ) | container-runnerのイベントパース中に不正なJSONが出力 | パースエラーがログされ処理が継続 |
| QE-260 | K(並行安全性) | DB flushとcloseが同時に呼ばれた場合 | データ損失なく安全にシャットダウン |
